Features

Everything built in

No extensions needed for the basics. Press Ctrl+K anywhere to search every command, tab, bookmark and setting.

Now Playing & lyrics

Whatever's playing on your PC (Spotify, YouTube, other apps) shows on the new tab with album art, seek, shuffle and repeat, plus lyrics that scroll along with the song.

Ad & tracker blocker

Blocks ads, trackers and cookie banners out of the box, with a per-site switch when something breaks.

Game mode

When a full-screen game is running, background tabs sleep and the browser steps back so the game gets your RAM and CPU. Music keeps playing.

Saved sessions

Save a window's tabs as "School" or "Gaming" and reopen them in one click whenever you need them.

Workspaces & tab groups

Keep separate sets of tabs, each with its own colour and, if you want, its own logins. Group tabs, pin them, or peek at a link without leaving the page.

Split view & vertical tabs

Two pages side by side with Ctrl+\, tabs down the side with Ctrl+Shift+M, and a focus mode that hides everything but the page.

Memory saver

Tabs you haven't used in a while go to sleep and wake up when you click them. Three levels, from off to maximum.

Bring your stuff

Import bookmarks, history and passwords from Chrome, Edge, Brave, Opera, Vivaldi or Firefox in a couple of clicks.

Password manager

Saves and fills logins, generates strong passwords and flags weak or reused ones. Passwords are encrypted with your Windows account.

Dragomir AI

Summarise a page, ask about it or have it explained, in a side panel next to what you're reading. Uses your own Claude API key.

Make it yours

Themes, accent colours, live wallpapers, clock fonts, tab styles, layouts and custom CSS. Almost every part of the look can be changed.

Extensions & more

Chrome Web Store extensions, reader mode, translation, picture-in-picture, full-page screenshots, sidebar web apps and user scripts.

Performance

Lighter on memory

The same six tabs (Wikipedia, GitHub, Hacker News, a simple page, the About page and a new tab) on a fresh profile, measured with the browser's own task manager.

Install

Up and running in a minute

Dragomir Browser comes as a zip: there's no installer, so nothing to set up and nothing left behind if you delete it.

Handy keys: Ctrl+K command palette, Ctrl+T new tab, Ctrl+Shift+T reopen a closed tab, Ctrl+\ split view, Ctrl+Shift+S screenshot.

  1. Download Dragomir Browser (a .zip file).
  2. Right-click the zip and choose Extract All…. Put it somewhere you'll keep, like your Documents folder. Don't run it from inside the zip.
  3. Open the extracted Dragomir Browser folder and double-click Dragomir Browser.exe. If Windows says it protected your PC, choose More info → Run anyway; that appears because the app isn't code-signed yet.
  4. It adds itself to the Start menu the first time it runs. To keep it handy, right-click its icon on the taskbar and choose Pin to taskbar.
  5. To bring over your bookmarks, history and passwords, open Settings → Import & export, pick your old browser and press Import.
  6. To open links in Dragomir, go to Settings → Windows & updates and choose Set as default.
  7. Updates install themselves. New versions download in the background, are checked against GitHub's fingerprint, and install when you restart; your tabs come back. You can turn this off in Settings → Windows & updates. If you have 1.0.0, download 1.0.1 once and extract it over the old folder; your tabs, bookmarks and settings are kept in %appdata%\Dragomir Browser, so nothing is lost.
