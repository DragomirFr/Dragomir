Firebase Realtime Database Setup

Connect a free Firebase database to push updates live to every visitor in real time

Quick 60-Second Setup:
1. Go to console.firebase.google.com and create a free project.
2. Click Build → Realtime Database → Create Database.
3. Under Rules, set ".read": true and ".write": true.
4. Copy the Database URL shown at the top and paste it into the field above!
