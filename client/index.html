Dragomir Client

A clean PvP client for Minecraft 26.3.

Download v1.5.1 Install guide

Fabric mod (.jar)673 KBMinecraft 26.3

Features

Everything in one menu

Press Right Shift in game to open the mod menu. Every mod has its own settings and an optional toggle key.

Draggable HUD

FPS, CPS, coordinates, keystrokes, armour, potions, ping and more. Drag, resize, nudge with arrow keys, or reset to a clean layout.

Minimap & world map

Terrain minimap with players and mobs, plus a full world map (M) that remembers everywhere you've explored.

Waypoints

On-screen markers with off-screen arrows, an automatic death waypoint, and one-key waypoints where you stand or look.

PvP tools

Reach display, combo counter, CPS graph, hitboxes, hit colour, custom crosshair, nametag health and toggle sprint.

Zoom & freelook

Hold C to zoom and scroll to adjust. Hold Left Alt to look around without turning.

Spotify

Now playing with album art on your HUD, and a pause-menu player with controls and volume (Windows).

Chat tweaks

Timestamps, stacked duplicates, chat search, right-click to copy, mention highlights and phrase filters.

Render

Fullbright, block outline, item physics, low fire, clear weather, time changer and no hurt cam.

Profiles & themes

Default, PvP, Building and Recording profiles, five HUD themes, and setup codes to share your config with friends.

Install

Up and running in a minute

Dragomir Client is a Fabric mod, so it runs in the normal Minecraft launcher.

Minecraft
26.3
Fabric Loader
0.20.1 or newer
Fabric API
Required
Java
25 (bundled with the launcher)
  1. Install Fabric Loader for Minecraft 26.3 with the Fabric installer.
  2. Download Fabric API for 26.3 from Modrinth.
  3. Download Dragomir Client, then put both jars in your mods folder: %appdata%\.minecraft\mods
  4. Open the Minecraft Launcher, pick the fabric-loader 26.3 profile and press Play. Press Right Shift in game to open the mods.
  5. Updates install themselves: when a new version is out, press Install on the main menu, then quit the game to finish.
